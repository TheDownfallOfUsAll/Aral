# AralLink for Numbers

A desktop-first web prototype for Grade 1 addition and subtraction. The prototype includes a student learning dashboard, lessons, a short interactive practice flow, progress and achievements, classroom student overview, and guardian/teacher notifications. Sample data and progress are held in local React state; there is no backend.

## Run locally

```powershell
npm install
npm run dev
```

Open the local address shown by Vite. To verify a production build, run `npm run build`.

## Increment 1 scope

- Addition and subtraction practice within 10
- Student progress, stars, badges, and lesson completion views
- Teacher classroom roster and progress overview
- Guardian/teacher notification feed
- Desktop web experience only; mobile screens and a mobile app are out of scope
